# Kanzlei Jähnig · Website preview

Responsive German law-firm website. Uses the user-uploaded original JPEG logo, byte-for-byte unchanged, on both pages. It is displayed proportionally, with no crop, filter, recoloring or re-encoding. Serif headings and grey/orange accents follow the logo's identity.

Serve the repository root with any static server or open `index.html`. GitHub Pages uses `main` and `/ (root)`. No build or external dependencies.

Names, qualifications, specialisms, dates and contact details come from the original firm website. No additional photography, quotations, testimonials or “Kontakt aufnehmen” call-to-action. Original imprint and full firm privacy notice remain linked; the local privacy page explains the preview's hosting.

Mobile navigation supports expanded state, link selection and Escape. Without JavaScript navigation remains visible. Direct telephone/email links and an optional external Maps link are available. No tracking, cookies, embedded maps, external fonts or forms.

## Typography

Self-hosted Oswald for headings and Figtree for navigation and body copy. These families were observed on Gleiss Lutz's website during the requested reference review. Open-source font files are from google/fonts; both SIL Open Font License files are included. No external font services are contacted. The original uploaded logo is unchanged.
